# Recepção de Dados

Produto da Plataforma Opus Open Finance para instituições que atuam como **Receptor de Dados** — consumindo dados de clientes (contas, cartões, crédito, investimentos, etc.) compartilhados via Open Finance Brasil.

> 📘 **Conteúdo compartilhado com Iniciação de Pagamentos**
> Os fluxos de **consentimento**, **redirecionamento**, **vínculo de dispositivo** e a **configuração/certificados** são os mesmos dos dois produtos. Consulte-os em [Iniciação de Pagamentos → Funcionamento](../iniciacaoDePagamentos/funcionamento/) para não duplicar.
