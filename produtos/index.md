# Produtos

A Plataforma Opus Open Finance oferece dois produtos para participação no Open Finance Brasil, que podem ser adquiridos e implantados de forma independente conforme o perfil de atuação da instituição:

| Produto | Para quem | Perfis regulatórios cobertos |
|---|---|---|
| [**Plataforma Opus Open Finance**](plataforma-opus-open-finance.html) | Instituições que precisam expor dados e/ou receber pagamentos | Detentor de Conta, Transmissor de Dados, Dados Abertos |
| [**OpusTPP**](opustpp.html) | Instituições que precisam consumir dados e/ou iniciar pagamentos em outras instituições | Iniciador de Transação de Pagamento (ITP), Receptor de Dados |
| [**Opus Data Receiver**](opus-data-receiver.html) | Complemento ao OpusTPP para atualização automática e consolidação de dados | Receptor de Dados |

> Uma mesma instituição pode contratar os dois produtos simultaneamente se atuar nos dois lados do ecossistema.
